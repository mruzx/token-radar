The board refits both halves against the snapshot’s own traded protocols: a size curve plus shrunk category effects prices what a token would be worth if it launched, and a logistic on age, family size, size and growth estimates the token odds. Implied value is the two multiplied. The watchlist is the floor: every protocol with at least $50M of TVL and no token on record. The early radar adds 138 pre-token protocols below that floor, and 20 off-list protocols above it whose parent is already recorded. How implied value is computed

Category effects

The value fit’s per-category effect on the multiple, shrunk toward 1.00 with ridge 256. A category with few traded tokens barely moves from 1.00.

CategoryEffect

A protocol records no token when its DefiLlama record carries no market cap, no CoinGecko id and no symbol. That is a statement about the record, never a guarantee the protocol has no token. Wrapped, staked and bridged products of tokens that already trade are off the board by the same rule. Off-list rows are sub-products above the $50M floor whose parent is already recorded; a token of their own would capture about half the value, so their implied value carries a 0.48 parent factor.
